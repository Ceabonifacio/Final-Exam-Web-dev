# CampusCycle

CampusCycle is a responsive, three-page student marketplace website prototype for exploring pre-loved school supplies.

## Files

- `index.html` — home page
- `services.html` — sample marketplace listings
- `about.html` — mission, steps, benefits, and contact placeholders
- `css/styles.css` — shared styling and responsive layouts
- `Logo.svg` — supplied project logo
- `assets/images/products/` — original local SVG product illustrations

## Open locally

Open `index.html` in a browser. The pages use relative links and do not need a server.

## Technology and assets

The site uses HTML5 and CSS3 only; there is no JavaScript or backend. The logo was provided with the project, and the product illustrations were made for this prototype. Poppins, Inter, and Material Symbols are linked from Google Fonts and have system-font fallbacks. No third-party product imagery is used.
